# Smart Attendance System

A Python-based Smart Attendance System that uses OpenCV and MediaPipe to detect faces through a webcam and automatically record attendance with timestamps.

## Features

* Real-time face detection
* Webcam integration
* Automatic attendance marking
* Timestamp logging
* CSV-based attendance storage
* Duplicate attendance prevention

## Tech Stack

* Python
* OpenCV
* MediaPipe
* Pandas
* NumPy

## Project Structure

```text
Smart-Attendance-System
```
